PulseLogger privacy policy

PulseLogger stores the user's health records on the phone and, if the user signs in, in the user's own Google Drive.

The app requests only the drive.file scope and can access only the files it creates. PulseLogger's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

No data is shared with third parties. Access can be revoked at myaccount.google.com/permissions.
